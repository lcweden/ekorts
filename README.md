# Ekorts

這是一個macOS Menu Bar工具，讓macOS下的筆劃輸入法鍵位行為更接近iOS。

## 行為

### 字母鍵盤

| 筆劃 | macOS | Ekorts |
| ---- | ----- | ------ |
| 丶   | U     | J      |
| 乛   | I     | K      |
| \*   | O     | L      |
| 一   | J     | U      |
| 丨   | K     | I      |
| 丿   | L     | O      |

### 數字鍵盤

| 筆劃 | macOS | Ekorts |
| ---- | ----- | ------ |
| 丶   | 4     | 1      |
| 乛   | 5     | 2      |
| \*   | 6     | 3      |
| 一   | 1     | 4      |
| 丨   | 2     | 5      |
| 丿   | 3     | 6      |

## Requirements

- macOS 15.6+
